# Sistema Integrado OLX — Shopping Car

Painel de gestão de veículos e integração oficial OLX. Cadastro único, controle de imagens e estoque, planejamento comercial de até 14 cidades e publicação de um anúncio por veículo pela API homologada.

> O projeto não replica anúncios idênticos em múltiplos municípios. A OLX restringe duplicações e exige integradores/planos autorizados.

Consulte as instruções completas de instalação e configuração após a implementação inicial.
